# Cartograph v2.1.8

Cartograph v2.1.8 is a dependency and release-footprint cleanup. It removes
unused development-only edges and the optional terminal-color stack while
preserving the native CLI, MCP protocol, search evidence, and PostgreSQL
runtime contracts shipped in v2.1.7.

## Dependency cleanup

- The MCP protocol tests now own their structured reference fixture instead of
  enabling a public search-crate test-support feature. Exact reference IDs,
  spans, confidence, provenance, and represented-site multiplicity remain
  asserted across JSON-RPC transport.
- Search serialization tests now assert every structured reference field from
  the typed packet directly, so removing the cross-crate fixture does not
  reduce wire-contract coverage.
- Unused agent, extractor, search, and MCP development dependencies are removed
  from their crate manifests and from the locked dependency graph.
- Clap no longer enables its optional color stack. Command help, error context,
  suggestions, usage text, derive support, and the existing `--no-color`
  compatibility flag remain available.

The production all-target dependency graph is eight packages smaller, and the
MCP crate's isolated all-target test graph no longer pulls the search/database
stack solely for one fixture.

## Upgrade notes

There is no schema migration or generation-digest change in v2.1.8. A current
V10 generation remains current when the indexed source is unchanged. The
resumable upgrade path remains:

```sh
cartograph upgrade --apply --project-path <PATH>
```

Cartograph v2.1.8 remains native Rust and PostgreSQL-only. PostgreSQL 18,
ParadeDB `pg_search` 0.25.0, and pgvector 0.8.4 or newer remain external runtime
services. No SQLite runtime, fallback, importer, or dependency is included.

## Verification

The release is built from the exact published `main` SHA after the pinned Rust,
PostgreSQL/ParadeDB, deterministic 1/2/4/8/16-worker, Sonar, archive, and
independent-review gates. The four native archives are checksum-verified,
allowlist and privacy audited, smoke-tested, and published with GitHub build
provenance.
