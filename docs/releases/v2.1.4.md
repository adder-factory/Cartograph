# Cartograph v2.1.4

Cartograph v2.1.4 adds generation-scoped numerical code intelligence and
extends the native MCP/CLI surface without making an LLM part of the static
evidence path.

## Highlights

- Added `cartograph numerical` and `cartograph_numerical` with bounded `sites`,
  `coverage`, `explain`, and non-executing `plan` modes. The first
  `rust_ast_v1` analyzer reports exact spans, operation and hazard categories,
  visible precision, confidence, provenance, and explicit unknowns.
- Added immutable `numerical_sites` storage, migration 26, and generation digest
  V7. Static numerical evidence is freshness-fenced and never stores source
  expressions or literal values.
- Kept static heuristics, runtime observations, and formal proof as separate
  evidence levels. Observation and formal adapters report `not_configured`
  rather than upgrading static evidence into a stronger claim.
- Expanded MCP numerical routing, review integration, status coverage, compact
  output, CLI compatibility, and the published 36-tool full profile.
- Hardened deterministic extraction, validation, COPY, retention, SCIP import,
  and worker-count identity for the additional numerical fact stream.
- Corrected the Windows v1-import future layout so the native Windows release
  builds and runs the same resumable import path.

## Upgrade notes

A normal index after upgrading publishes a V7 generation with numerical
evidence. Older complete generations remain readable but report stale until
the current digest contract is published. No SQLite runtime or migration path
was added; Cartograph v2 continues to require PostgreSQL 18, ParadeDB
`pg_search`, and pgvector.

## Verification

The release is built from the exact published `main` SHA after the Rust,
PostgreSQL/ParadeDB, deterministic-worker, Sonar, and independent-review gates.
The four native archives are checksum-verified, smoke-tested, and published
with GitHub build provenance.
