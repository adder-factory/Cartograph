# Cartograph v2.1.16

Cartograph v2.1.16 clears the eleven code-health findings carried by v2.1.15
without suppressing detectors, changing severity, excluding source, or reducing
the graph's evidence. The release decomposes a small set of overloaded Rust
paths into typed, bounded operations while preserving their public behavior.

## Extraction and indexing clarity

- C-family declaration and function extraction now separates recognition,
  symbol emission, type capture, scope management, and body traversal. Existing
  C, C++, CUDA, Objective-C, and Slang facts retain their deterministic symbol,
  signature, ownership, and reference contracts.
- Invocation capture now isolates Rust receiver resolution, oversized Go
  selector handling, JavaScript dynamic dispatch, and the default exact
  reference path. Static JavaScript chains continue to retain both exact and
  bounded dispatch evidence where applicable.
- WESL nested import traversal carries its prefix and depth as one bounded
  branch value. Native parsing and spilled-generation completion likewise use
  typed request/completion records instead of widening positional interfaces.
- Extractor, indexer, and agent regression suites continue to prove identical
  worker-count output, cancellation, bounded spill behavior, language-family
  resolution, and current-source publication.

## Agent and MCP boundaries

- Native pipeline reports convert parse-cache and generation-storage metrics
  through focused conversions, reducing fan-out while preserving every
  published metric.
- Index/source reconciliation carries its report, options, and cancellation
  fence as one operation value.
- MCP admin-job and public tool errors route embedding, retrieval, enrichment,
  and source failures through focused classifiers. A regression table locks the
  existing admin categories, public error codes, and redacted messages.

## Upgrade

Use the resumable upgrade path:

```sh
cartograph upgrade --apply --project-path <PATH> --json
```

Require `completed: true`. Reopen an attached agent host only when the report
sets `restartRequired: true`; an already attached MCP child cannot hot-load the
replacement binary.

Cartograph v2.1.16 remains native Rust and PostgreSQL-only. It has no SQLite
runtime, fallback, importer, or dependency. Native archives do not bundle
PostgreSQL, ParadeDB, pgvector, a database, or a container image.
